# 插件矩阵

## 组件分化

三个入口使用相同的组件 API，按需要选择默认能力：

| 组件           | 导入入口                                  | 定位                                     |
| -------------- | ----------------------------------------- | ---------------------------------------- |
| `Fluxdown`     | `@fluxdown/taro` 或 `@fluxdown/taro/full` | 完整预设，提供高亮、公式、CJK 与 Emoji。 |
| `FluxdownLite` | `@fluxdown/taro/lite`                     | 基础 Markdown 展示，按需添加能力。       |
| `FluxdownRaw`  | `@fluxdown/taro/raw`                      | 自行传入完整的 `plugins`，组合全部能力。 |

### 所在包

<PluginTag type="taro-plugins" /> 对应
`@fluxdown/taro-plugins`，在共用的渲染插件上提供 Taro 插槽。

<PluginTag type="react-base-plugins" /> 对应
`@fluxdown/react-base-plugins`，提供共用的渲染与语法插件。

### 导入规则

> 从 `<包名>/plugins/<插件目录>` 导入。去掉名称末尾的 `Plugin`，将剩余部分转换为小写中划线形式，例如 `CodePrismPlugin` 对应 `code-prism`，`TexMathjaxKatexPlugin` 对应 `tex-mathjax-katex`。包名以表格中的标记为准。

```ts
import { CjkPlugin } from '@fluxdown/react-base-plugins/plugins/cjk';
import { CodePrismPlugin } from '@fluxdown/taro-plugins/plugins/code-prism';
import { TexMathjaxKatexPlugin } from '@fluxdown/taro-plugins/plugins/tex-mathjax-katex';
```

> `PRESET_FULL_PLUGINS` 从 `@fluxdown/taro-plugins/full` 导入，`PRESET_LITE_PLUGINS` 从 `@fluxdown/taro-plugins/lite` 导入。

通过组件的 `plugins` 属性添加插件。声明、组合与配置方式见[综合插件](./aggregate.md)。
