# 插件矩阵 - Fluxdown Vue Lynx {#插件矩阵}

## 组件分化

| 组件           | 入口                                              | 默认能力                                 |
| -------------- | ------------------------------------------------- | ---------------------------------------- |
| `Fluxdown`     | `@fluxdown/vue-lynx` 或 `@fluxdown/vue-lynx/full` | Shiki 代码高亮、SVG 公式、CJK 与 Emoji。 |
| `FluxdownLite` | `@fluxdown/vue-lynx/lite`                         | 基础 Markdown、表格、图片与流式效果。    |
| `FluxdownRaw`  | `@fluxdown/vue-lynx/raw`                          | 自行传入完整的 `plugins`。               |

Full 的高亮支持 Bash、CSS、HTML、JavaScript、JSON、Python 和 TypeScript；未识别的语言保留纯文本。Lite 的代码块显示源码。

`build.tex` 默认为 `false`。开启后，Full 使用 MathJax SVG 排版，宿主需接入 SVG XElement；Lite 显示公式源码，也可按需添加 `TexMathJaxPlugin`。

## 代码高亮 {#code-highlighting}

Full 使用 Shiki 高亮，初始化完成前或失败时显示源码。Android 需要 Lynx 3.8 或更新版本的[后台线程 WebAssembly 支持](https://lynxjs.org/4.1/guide/scripting-runtime/webassembly.html)。也可通过 `CodePrismPlugin` 使用不依赖 WebAssembly 的高亮。

## 所在包与导入

<PluginTag type="vue-lynx-plugins" /> 对应 `@fluxdown/vue-lynx-plugins`，包含
Lynx 的综合插件、render 和 slot。

> 使用 `@fluxdown/vue-lynx-plugins/plugins/<插件目录>` 导入。目录名取导出名称，去掉 `Plugin` 后转成小写中划线形式，例如 `CodeShikiPlugin` 对应 `code-shiki`。

```tsx
import { CodeShikiPlugin } from '@fluxdown/vue-lynx-plugins/plugins/code-shiki';
import { HeadingPlugin } from '@fluxdown/vue-lynx-plugins/plugins/heading';
```

> 预置列表 `PRESET_FULL_PLUGINS`、`PRESET_LITE_PLUGINS` 分别从 `@fluxdown/vue-lynx-plugins/full`、`@fluxdown/vue-lynx-plugins/lite` 导入，可直接传给 `FluxdownRaw`。

组件的 `plugins` 参数可以继续扩展任意预设。配置与组合方式见[综合插件](./aggregate.md)。

## 共用 Vue 基础层

<PluginTag type="vue-base-plugins" /> 对应
`@fluxdown/vue-base-plugins`，提供共享渲染插件、CJK、Emoji 和
Patch。按表中所在包导入：

```ts
import { CjkPlugin } from '@fluxdown/vue-base-plugins/plugins/cjk';
```
