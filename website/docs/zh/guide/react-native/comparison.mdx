## 在网页中使用

预览通过 [React Native Web](https://necolas.github.io/react-native-web/) 渲染原生组件。组件和插槽与 iOS、Android 共用源码。

Expo Web 会处理基本的平台配置。使用其他网页打包器时，安装 React Native Web 与 React DOM，并将 `react-native` 精确别名到 `react-native-web`。本仓库的[共享 Web 配置](https://github.com/hexmora/fluxdown/blob/main/scripts/build/react-native-web.ts) 还设置了 `.web.*` 文件的优先解析，并处理当前 `react-native-svg` 的资源注册与原生音效模块兼容问题，可作为 Full 和 Lite 的 Web 接入参考。

## 哪些差异是正常的

标题、正文、间距与主题尽量保持一致。系统字体的字形与换行、原生 Text 的布局和动画实现会产生少量差异；代码高亮、公式和图表还使用不同的渲染库。

网页预览方便比较相同输入，不能替代真机检查。发布应用前，仍应在目标设备上确认字体、长表格、图片与链接交互。
