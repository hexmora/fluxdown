# 体积优化

Fluxdown 提供 Lite 与 Full 两个入口。它们共享 Markdown 排版、代码复制和流式能力，主要区别是代码高亮与公式排版所需的依赖。只需要基础显示时选择 Lite；需要完整高亮与公式支持时使用默认的 Full。

## Lite：保留基础显示

从 `fluxdown/lite` 导入 `FluxdownLite`。代码使用等宽字体显示，公式显示 LaTeX 源码；此入口不引入 Prism、Shiki、KaTeX 或 MathJax。

```tsx
import { FluxdownLite } from 'fluxdown/lite';

export function Message({ text }: { text: string }) {
  return <FluxdownLite build={{ tex: true }} text={text} />;
}
```

下面的演示保留代码语言与复制按钮，代码没有语法着色，公式显示源码。`build={{ tex: true }}` 在两个版本中都用于开启公式语法。

<PackDemo variant="lite" />

Lite 包含以下全部 18 个插件包，由 `@fluxdown/react-presets/lite` 的 `PRESET_LIGHT_PLUGINS` 提供。每个包都可通过 `@fluxdown/react-presets/plugins/<目录>` 独立导入，包内包含该功能的 render 和／或 slot 插件。

| 插件包               | 目录            | 能力                                             |
| -------------------- | --------------- | ------------------------------------------------ |
| `PatchPlugin`        | `patch`         | 按文本范围替换内容                               |
| `EffectShadPlugin`   | `effect-shad`   | 流式输出末尾渐变                                 |
| `EffectScalePlugin`  | `effect-scale`  | 逐字缩放、淡入与模糊消退                         |
| `EffectChunkPlugin`  | `effect-chunk`  | 分组淡入文字                                     |
| `EffectSuffixPlugin` | `effect-suffix` | 末尾光标与圆点                                   |
| `CodePlugin`         | `code`          | 代码容器、语言与复制工具栏，使用等宽字体显示源码 |
| `EmphasisPlugin`     | `emphasis`      | 斜体文字                                         |
| `ImagePlugin`        | `image`         | 图片与地址检查                                   |
| `LinkPlugin`         | `link`          | 链接与地址检查                                   |
| `ListPlugin`         | `list`          | 有序、无序与任务列表                             |
| `ParagraphPlugin`    | `paragraph`     | 段落排版                                         |
| `StrongPlugin`       | `strong`        | 加粗文字                                         |
| `TablePlugin`        | `table`         | 表格、单元格与列对齐                             |
| `TexPlugin`          | `tex`           | 显示 LaTeX 源码，不加载公式排版引擎              |
| `HeadingPlugin`      | `heading`       | 一至六级标题                                     |
| `BreakLinePlugin`    | `break-line`    | 换行                                             |
| `BlockquotePlugin`   | `blockquote`    | 引用块                                           |
| `FallbackPlugin`     | `fallback`      | 普通文本、行内代码与其余基础节点                 |

## Full：代码高亮与公式排版

从 `fluxdown` 导入 `Fluxdown`，也可以显式使用 `fluxdown/full`。Full 使用 Shiki 为代码高亮，公式渲染器按需加载，先使用 KaTeX，无法渲染时再回退到 MathJax；加载期间仍显示公式源码。

```tsx
import { Fluxdown } from 'fluxdown';

export function Message({ text }: { text: string }) {
  return <Fluxdown build={{ tex: true }} text={text} />;
}
```

这个演示使用与 Lite 相同的输入，展示语法高亮和排版后的公式：

## 更多备选插件

Lite 和 Full 都没有预装以下两种方案，可以按需组合。先运行 `pnpm add @fluxdown/react-presets` 安装扩展包。

| 插件包            | 导入路径                                     | 适用情况                                                      |
| ----------------- | -------------------------------------------- | ------------------------------------------------------------- |
| `CodePrismPlugin` | `@fluxdown/react-presets/plugins/code-prism` | 使用 Prism 实现代码高亮。                                     |
| `TexKatexPlugin`  | `@fluxdown/react-presets/plugins/tex-katex`  | 仅按需加载 KaTeX，不包含 MathJax；无法排版时显示 LaTeX 源码。 |

在 Lite 基础上补充这两个插件，就能选择自己的高亮与公式依赖：

```tsx
import { CodePrismPlugin } from '@fluxdown/react-presets/plugins/code-prism';
import { TexKatexPlugin } from '@fluxdown/react-presets/plugins/tex-katex';
import { FluxdownLite } from 'fluxdown/lite';

const plugins = [CodePrismPlugin, TexKatexPlugin];

export function Message({ text }: { text: string }) {
  return <FluxdownLite build={{ tex: true }} plugins={plugins} text={text} />;
}
```

Lite 和 Full 的 `plugins` 都是可选参数，传入的插件优先于预设。若目的是减少依赖，从 Lite 开始添加需要的能力；覆盖 Full 的插件不会移除 Full 已引入的 Shiki 或 MathJax。

需要完全控制预设时，从 `fluxdown/raw` 导入 `FluxdownRaw`，并显式传入必填的 `plugins`。例如，`plugins={PRESET_LIGHT_PLUGINS}` 使用全部轻量插件，也可以自行列出所需的插件包。
