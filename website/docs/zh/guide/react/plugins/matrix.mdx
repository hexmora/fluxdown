# 插件矩阵

## 组件分化

React Lite 和 React Full 使用相同的组件 API，按需要选择默认能力：

| 组件           | 导入入口                      | 定位                                                         |
| -------------- | ----------------------------- | ------------------------------------------------------------ |
| `FluxdownLite` | `fluxdown/lite`               | 尽量减小体积，提供基础 Markdown 展示，适合按需添加能力。     |
| `Fluxdown`     | `fluxdown` 或 `fluxdown/full` | 提供更完善的 Markdown 功能和展示效果，适合直接获得完整体验。 |

需要自行选择全部插件时，使用 `fluxdown/raw` 的 `FluxdownRaw`，并传入 `plugins`。

### 所在包

- <PluginTag type="react-plugins" /> 对应 `@fluxdown/react-plugins`，提供面向
  React DOM 的综合插件。
- <PluginTag type="react-base-plugins" /> 对应
  `@fluxdown/react-base-plugins`，提供不依赖 DOM 的基础插件，可供其他 React
  平台扩展。

### 导入规则

1. 按表格选择插件所在包，使用 `<包全名>/plugins/<插件目录>` 导入。
2. 插件目录由导出名称去掉 `Plugin` 后缀，再转为小写中划线形式。例如，`CodePrismPlugin` 对应 `code-prism`，`TexMathjaxKatexPlugin` 对应 `tex-mathjax-katex`，`CjkPlugin` 对应 `cjk`。

```tsx
import { CodePrismPlugin } from '@fluxdown/react-plugins/plugins/code-prism';
import { CjkPlugin } from '@fluxdown/react-base-plugins/plugins/cjk';
```

通过组件的 `plugins` 参数添加所需插件；声明、组合与配置方式见[综合插件](./aggregate.md)。
