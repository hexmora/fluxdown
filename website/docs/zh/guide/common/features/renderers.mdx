# 横向演示

同一份 Markdown、同一组文本片段，在 React、Vue、React Native、Lynx、Solid 和 Taro 中同时展开。切换静态或流式内容，查看排版与四种动画效果；窄屏下可以横向滚动查看各列。

所有渲染库默认选中。用中间的多选按钮保留要对比的列，左右滚动查看更多。

<RendererDemo />

每列会平滑跟随新内容到底部。向上滚动即可停下来阅读，回到底部后继续跟随。暂停和重播会同时控制所有渲染库。

React 与 Vue 使用浏览器 DOM；React Native 使用 React Native Web；Lynx 使用 Lynx Web 运行时；Solid 使用浏览器 DOM；Taro 使用其 H5 组件。它们共享 Markdown 与流式配置，字体、换行和动画细节会随渲染环境有所不同。

想用自己的内容试一试？前往 [Playground](/playground)，可在六种渲染库之间切换。
