# 横向演示

同一份 Markdown、同一组文本片段，在 React、Vue、Svelte、React Native、Lynx、Solid 和 Taro 中同时展开。切换静态或流式内容，查看排版与四种动画效果；窄屏下可以横向滚动查看各列。

默认选中 React、Vue 和 Svelte。用中间的多选按钮选择任意数量的渲染库，至少保留一个；选择会自动保存，下次访问时恢复。左右滚动可查看更多列。

<RendererDemo />

每列会平滑跟随新内容到底部。向上滚动即可停下来阅读，回到底部后继续跟随。暂停和重播会同时控制所有渲染库。

React、Vue、Svelte 和 Solid 使用浏览器 DOM；React Native 使用 React Native Web；Lynx 使用 Lynx Web 运行时；Taro 使用其 H5 组件。它们共享 Markdown 与流式配置，字体、换行和动画细节会随渲染环境有所不同。

想用自己的内容试一试？前往 [Playground](/playground)，可在七种渲染库之间切换。
