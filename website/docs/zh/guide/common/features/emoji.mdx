# Emoji 短码

`EmojiPlugin` 将 `:smile:`、`:+1:` 等 GitHub 风格的 emoji 短码转换为 Unicode 表情。React、Vue、Solid、React Native 和 Lynx 的 Full 组件默认包含此插件，Lite 组件可按需添加。

<FrameworkCodeTabs>

```tsx
import { Fluxdown } from 'fluxdown';

export function Message() {
  return <Fluxdown text="Hello :smile: Great work :+1:" />;
}
```

```vue
<script setup lang="ts">
import { Fluxdown } from '@fluxdown/vue';
</script>

<template>
  <Fluxdown text="Hello :smile: Great work :+1:" />
</template>
```

```tsx
import { Fluxdown } from '@fluxdown/solid';

export function Message() {
  return <Fluxdown text="Hello :smile: Great work :+1:" />;
}
```

```tsx
import { Fluxdown } from '@fluxdown/react-native';

export function Message() {
  return <Fluxdown text="Hello :smile: Great work :+1:" />;
}
```

```tsx
import { Fluxdown } from '@fluxdown/lynx';

export function Message() {
  return <Fluxdown text="Hello :smile: Great work :+1:" />;
}
```

</FrameworkCodeTabs>

输出为「Hello 😄 Great work 👍」。表情使用系统字体，具体外观取决于设备。

## 支持的内容

短码可用于 Markdown 文本，包括标题、列表、表格和链接文字。未知短码，以及 `:smile` 这样尚未闭合的输入，会保留原文。流式输出时，已识别的短码在结尾冒号到达后转换为表情。

行内代码和围栏代码块保留源码。例如，`` `:smile:` `` 会显示 `:smile:`，不会转换为表情。

## 引入插件

各框架的 Full 组件已内置 `EmojiPlugin`，无需手动注册。使用 Core 或 Lite 组件时，先安装对应的插件包：

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'Solid', 'React Native', 'Lynx']}>

```sh
pnpm add @fluxdown/core-plugins
```

```sh
pnpm add @fluxdown/react-base-plugins
```

```sh
pnpm add @fluxdown/vue-plugins
```

```sh
pnpm add @fluxdown/solid-plugins
```

```sh
pnpm add @fluxdown/react-base-plugins
```

```sh
pnpm add @fluxdown/lynx-plugins
```

</FrameworkCodeTabs>

Core 将 `EmojiRemarkPlugin` 加入[快速开始](../../core/quick-start.md)的 `remarks` 输入；组件则通过 `plugins` 扩展预设：

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'Solid', 'React Native', 'Lynx']}>

```ts
import { EmojiRemarkPlugin } from '@fluxdown/core-plugins/plugins/remark/emoji';

const remarks = [EmojiRemarkPlugin];
```

```tsx
import { EmojiPlugin } from '@fluxdown/react-base-plugins/plugins/emoji';
import { FluxdownLite } from 'fluxdown/lite';

type MessageProps = {
  text: string;
};

export function Message({ text }: MessageProps) {
  return <FluxdownLite plugins={EmojiPlugin} text={text} />;
}
```

```vue
<script setup lang="ts">
import { EmojiPlugin } from '@fluxdown/vue-plugins/plugins/emoji';
import { FluxdownLite } from '@fluxdown/vue/lite';

defineProps<{ text: string }>();
</script>

<template>
  <FluxdownLite :plugins="EmojiPlugin" :text="text" />
</template>
```

```tsx
import { EmojiPlugin } from '@fluxdown/solid-plugins/plugins/emoji';
import { FluxdownLite } from '@fluxdown/solid/lite';

type MessageProps = {
  text: string;
};

export function Message(props: MessageProps) {
  return <FluxdownLite plugins={EmojiPlugin} text={props.text} />;
}
```

```tsx
import { EmojiPlugin } from '@fluxdown/react-base-plugins/plugins/emoji';
import { FluxdownLite } from '@fluxdown/react-native/lite';

type MessageProps = {
  text: string;

```

```tsx

  text: string;
```

## 关闭转换

将 `EmojiPlugin` 与 `config` 放在同一个插件包中，可以按需禁用此功能。Core 使用带 `disabled` 配置的 remark 插件条目：

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'Solid', 'React Native', 'Lynx']}>

```ts
import type { IPluggable, IRemarkPlugin } from '@fluxdown/types';

import { EmojiRemarkPlugin } from '@fluxdown/core-plugins/plugins/remark/emoji';

const remarks: IPluggable<IRemarkPlugin, unknown>[] = [
  [EmojiRemarkPlugin, { disabled: true }],
];
```

```tsx
import { EmojiPlugin } from '@fluxdown/react-base-plugins/plugins/emoji';
import { Fluxdown } from 'fluxdown';

type MessageProps = {
  text: string;
};

export function Message({ text }: MessageProps) {
  return (
    <Fluxdown
      plugins={{
        ...EmojiPlugin,
        config: { 'remark-emoji': { disabled: true } },
      }}
      text={text}
    />
  );
}
```

```vue
<script setup lang="ts">
import { EmojiPlugin } from '@fluxdown/vue-plugins/plugins/emoji';
import { Fluxdown } from '@fluxdown/vue';

const plugins = {
  ...EmojiPlugin,
  config: { 'remark-emoji': { disabled: true } },
};

defineProps<{ text: string }>();
</script>

<template>
  <Fluxdown :plugins="plugins" :text="text" />
</template>
```

```tsx
import { EmojiPlugin } from '@fluxdown/solid-plugins/plugins/emoji';
```
