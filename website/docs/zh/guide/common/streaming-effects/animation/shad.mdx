# 末尾渐变

`shad` 让每个新出现的字符从透明渐变到不透明。每个字符从出现的那一刻起独立播放自己的淡入，不再跟随显示进度，因此输出暂停时渐变也会自然完成。已经显示的内容保持不变。

## 使用方式

选择对应框架查看代码。Core 示例中的 `mappers` 传入 [Core 输入](../../../core/quick-start.md)，并显式启用 mapper；组件通过 `streaming.effect` 启用相同效果，并内置视觉渲染器。

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'React Native', 'Lynx']}>

```ts
import type { MapperPluggable } from '@fluxdown/core';
import { Smooth } from '@fluxdown/core-plugins/plugins/mapper/smooth';
import { Shad } from '@fluxdown/core-plugins/plugins/mapper/shad';

const mappers: MapperPluggable[] = [
  [Smooth, { enabled: true }],
  [Shad, { enabled: true }],
];
```

```tsx
import { Fluxdown } from 'fluxdown';

export function Message({ text }: { text: string }) {
  return <Fluxdown streaming={{ effect: 'shad' }} text={text} />;
}
```

```vue
<script setup lang="ts">
import { Fluxdown } from '@fluxdown/vue';

defineProps<{ text: string }>();
</script>

<template>
  <Fluxdown :streaming="{ effect: 'shad' }" :text="text" />
</template>
```

```tsx
import { Fluxdown } from '@fluxdown/react-native';

  return <Fluxdown streaming={{ effect: 'shad' }} text={text} />;
}
```


## 渐变如何自适应

字符到达越快，同时在淡入的字符就越多。为了让渐变尾部大约保持 `length` 个字符，当在播字符超过 `length` 时，新到的一批字符会使用更短的淡入：时长为 `duration × length ÷ 在播字符数`。在播字符不多时，每批都使用完整的 `duration`。因此一次性到达的大段文字会很快稳定，较慢的输出则会柔和地淡入。

## 配置

以下字段属于 `['shad', config]` 中的 `shad` 配置对象。

### enabled <span className="field-tag">可选</span> {#enabled}

**类型：** `boolean`

**默认值：** `true`

是否开启末尾渐变。

### length <span className="field-tag">可选</span> {#length}

**类型：** `number`

**默认值：** `10`

渐变希望同时保持在淡入中的字符数。小数向下取整；`0` 关闭渐变，负数按 `0` 处理，非有限值使用默认值。

### duration <span className="field-tag">可选</span> {#duration}

**类型：** `number`

**默认值：** `400`

单个字符最长的淡入时长，单位为毫秒，在播字符不超过 `length` 时使用。负数按 `0` 处理，非有限值使用默认时长。

> 早期版本使用渐变遮罩为固定宽度的末尾着色。`maskWidth` 和 `hideDelay` 已随遮罩一起移除。
