# 动画效果

动画控制新内容如何出现。只有启用 `streaming` 后效果才会生效；省略 `streaming` 或设为 `false` 时不显示动画效果。[平滑化](../smoothing.mdx)控制收到的文字何时变得可见，两者可以配合使用。

## Effect 输入形式

以下输入形式对应 React 组件的 `streaming.effect` 配置。自定义效果沿用 [mapper 插件](../../../core/plugins/mapper.mdx)的配置方式。

| 输入形式                                              | 含义                                    |
| ----------------------------------------------------- | --------------------------------------- |
| `false`                                               | 关闭视觉效果。                          |
| 省略或 `true`                                         | 使用默认配置的 [`scale`](./scale.mdx)。 |
| 效果名称，例如 `'scale'`                              | 使用该效果的默认配置。                  |
| `[name, config]`，例如 `['scale', { duration: 250 }]` | 配置指定的内置效果。                    |
| `Mapper`                                              | 使用自定义 mapper 的默认配置。          |
| `[Mapper, config]`                                    | 配置自定义 mapper。                     |
| 数组，例如 `['scale', ['suffix', { type: 'dot' }]]`   | 组合内置效果或自定义效果。              |

## 内置效果

点击下方效果名称查看实时演示与配置；选择与组合方式见 [Effect 输入形式](#effect-输入形式)。

| Effect                   | 说明                                           |
| ------------------------ | ---------------------------------------------- |
| [`shad`](./shad.mdx)     | 每个新字符独立淡入，并随输出节奏自适应。       |
| [`scale`](./scale.mdx)   | 让新出现的字符逐字缩放、淡入，并消退轻微模糊。 |
| [`chunk`](./chunk.mdx)   | 将每次可见更新中的新文字作为一组淡入。         |
| [`suffix`](./suffix.mdx) | 在可见内容末尾追加光标、圆点或自定义标记。     |

每个效果的子页都包含实时演示、React 组件示例与配置字段。配置字段支持普通值或可读闭包。效果在平滑化之后运行；`priority` 控制 mapper 顺序，`disabled` 排除某项效果。
