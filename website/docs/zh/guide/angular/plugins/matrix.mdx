# 插件矩阵

## 组件分化

三个入口使用相同的组件 API，按需要选择默认能力：

| 组件           | 导入入口                 | 定位                                     |
| -------------- | ------------------------ | ---------------------------------------- |
| `Fluxdown`     | `@fluxdown/angular`      | 完整预设，提供高亮、公式和图表等能力。   |
| `FluxdownLite` | `@fluxdown/angular/lite` | 基础 Markdown 展示，按需添加能力。       |
| `FluxdownRaw`  | `@fluxdown/angular/raw`  | 自行传入完整的 `plugins`，组合全部能力。 |

### 所在包

<PluginTag type="angular-plugins" /> 对应 `@fluxdown/angular-plugins`，提供
Angular 的综合插件、渲染器和插槽。

### 导入规则

> 使用 `@fluxdown/angular-plugins/plugins/<插件目录>` 导入。插件目录由名称去掉 `Plugin` 后缀，再转为小写中划线，例如 `CodeShikiPlugin` 对应 `code-shiki`，`TexMathjaxKatexPlugin` 对应 `tex-mathjax-katex`。

```ts
import { CodeShikiPlugin } from '@fluxdown/angular-plugins/plugins/code-shiki';
import { TexMathjaxKatexPlugin } from '@fluxdown/angular-plugins/plugins/tex-mathjax-katex';
```

> `PRESET_FULL_PLUGINS` 与 `PRESET_LITE_PLUGINS` 分别从 `@fluxdown/angular-plugins/full`、`@fluxdown/angular-plugins/lite` 导入。

通过组件的 `plugins` 添加所需插件；声明、组合与配置方式见[综合插件](./aggregate.md)。
