# Remark plugins

Remark plugins run while Markdown is parsed into its syntax tree, MDAST. Use them to add a syntax extension or adapt an existing unified remark plugin.

## Declare a plugin

For example, `remark-cjk-friendly` improves emphasis parsing around Chinese, Japanese, and Korean punctuation:

```sh
pnpm add @fluxdown/core-presets remark-cjk-friendly
```

```ts
import { BaseRemarkPlugin } from '@fluxdown/core-presets/plugins/remark/base';
import remarkCjkFriendly from 'remark-cjk-friendly';

class CjkSyntaxPlugin extends BaseRemarkPlugin {
  static readonly key = 'remark-cjk-syntax';

  readonly plugin = remarkCjkFriendly;
}

const remarks = [CjkSyntaxPlugin];
```

`key` identifies the plugin. `plugin` is the unified plugin that registers the syntax extension. Core already supplies the Markdown parser.

## Use it

Add `remarks` to the Core inputs from the [quick start](../quick-start.md). Existing presets stay enabled.

If your unified plugin needs options, accept them in the class constructor and create a `plugin` function that closes over those options. Pass them as `[YourPlugin, options]`.

> remark extensions can also transform MDAST. Use [repair](./repair.mdx) when the change should follow Core's repair switches or target the streaming tail.

## Supported plugins

Append a subpath from the table to `@fluxdown/core-presets/plugins/remark/` to import a plugin. For example, `code-meta` becomes `@fluxdown/core-presets/plugins/remark/code-meta`.

A check marks plugins included in `PRESET_REMARK_PLUGINS`, exported from `@fluxdown/core-presets/presets/remark`. Core registers these automatically; add plugins without a check explicitly.

| Plugin                            | Subpath                |    Built in     | Purpose                                                                                  |
| --------------------------------- | ---------------------- | :-------------: | ---------------------------------------------------------------------------------------- |
| `ApplyRepairsRemarkPlugin`        | `apply-repairs`        | <PresetCheck /> | Applies repair plugins so unfinished Markdown has a suitable presentation at each stage. |
| `CodeMetaRemarkPlugin`            | `code-meta`            | <PresetCheck /> | Preserves metadata after a fenced code block's language label for renderers.             |
| `EmojiRemarkPlugin`               | `emoji`                |                 | Converts [emoji shortcodes](../../common/features/emoji.md) into Unicode emoji.          |
| `PatchesRemarkPlugin`             | `patches`              | <PresetCheck /> | Marks text ranges that the app will replace with custom content.                         |
| `SyntaxAutolinkRemarkPlugin`      | `syntax-autolink`      | <PresetCheck /> | Converts recognized URLs and email addresses into links.                                 |
| `SyntaxFootnoteRemarkPlugin`      | `syntax-footnote`      | <PresetCheck /> | Supports footnote references and definitions; requires `build.footnote`.                 |
| `SyntaxHtmlAllowedRemarkPlugin`   | `syntax-html-allowed`  | <PresetCheck /> | Controls which raw HTML tags are allowed and treats other tags as text.                  |
| `SyntaxMathRemarkPlugin`          | `syntax-math`          | <PresetCheck /> | Supports formulas and their intermediate streaming states; requires `build.tex`.         |
| `SyntaxPolicyRemarkPlugin`        | `syntax-policy`        | <PresetCheck /> | Controls whether indented code blocks and Setext headings are enabled.                   |
| `SyntaxSoftEndlineRemarkPlugin`   | `syntax-soft-endline`  | <PresetCheck /> | Displays plain newlines as line breaks.                                                  |
| `SyntaxStrikethroughRemarkPlugin` | `syntax-strikethrough` | <PresetCheck /> | Supports strikethrough.                                                                  |
| `SyntaxTableRemarkPlugin`         | `syntax-table`         | <PresetCheck /> | Supports Markdown tables.                                                                |
| `SyntaxTaskListRemarkPlugin`      | `syntax-task-list`     | <PresetCheck /> | Supports task lists with checkboxes.                                                     |
| `TableNoralizerRemarkPlugin`      | `table-noralizer`      | <PresetCheck /> | Fills in table column alignment as the number of columns changes.                        |
