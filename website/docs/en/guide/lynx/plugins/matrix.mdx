# Plugin matrix

## Component variants

| Component      | Entry                                     | Included features                                            |
| -------------- | ----------------------------------------- | ------------------------------------------------------------ |
| `Fluxdown`     | `@fluxdown/lynx` or `@fluxdown/lynx/full` | Adds Shiki highlighting, CJK and Emoji to the base features. |
| `FluxdownLite` | `@fluxdown/lynx/lite`                     | Basic Markdown, tables, images and streaming effects.        |
| `FluxdownRaw`  | `@fluxdown/lynx/raw`                      | Requires your complete `plugins` list.                       |

Full highlights Bash, CSS, HTML, JavaScript, JSON, Python and TypeScript. Unrecognized languages remain plain text. Lite displays code as source text.

Both presets provide a `Tex` slot. `build.tex` defaults to `false`; enabling it displays formula source. Add `TexSvgPlugin` and integrate SVG XElement in the host to typeset math.

## Package and imports

<PluginTag type="lynx-plugins" /> is `@fluxdown/lynx-plugins`, which provides
Lynx composite plugins, render plugins and slots.

> Import from `@fluxdown/lynx-plugins/plugins/<plugin-directory>`. Remove the `Plugin` suffix from the export name and convert it to lowercase hyphenated words: `CodeShikiPlugin` becomes `code-shiki`.

```tsx
import { CodeShikiPlugin } from '@fluxdown/lynx-plugins/plugins/code-shiki';
import { HeadingPlugin } from '@fluxdown/lynx-plugins/plugins/heading';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/lynx-plugins/full`, or `PRESET_LITE_PLUGINS` from `@fluxdown/lynx-plugins/lite`, to pass a preset directly to `FluxdownRaw`.

The component's `plugins` prop can extend any preset. See [composite plugins](./aggregate.md) for configuration and composition.
