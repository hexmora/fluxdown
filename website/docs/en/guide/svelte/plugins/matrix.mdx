# Plugin matrix

## Component variants

The three entry points share the same component API with different default capabilities:

| Component      | Import                                        | Purpose                                                          |
| -------------- | --------------------------------------------- | ---------------------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/svelte` or `@fluxdown/svelte/full` | Full Markdown presentation with highlighting, math and diagrams. |
| `FluxdownLite` | `@fluxdown/svelte/lite`                       | Basic presentation, ready for selected additions.                |
| `FluxdownRaw`  | `@fluxdown/svelte/raw`                        | Takes the complete `plugins` list you supply.                    |

## Package and imports

<PluginTag type="svelte-plugins" /> refers to `@fluxdown/svelte-plugins`,
containing Svelte plugin packs, render plugins and slots.

> Import from `@fluxdown/svelte-plugins/plugins/<plugin-directory>`. Remove the `Plugin` suffix from the export name and convert it to kebab case: `CodeShikiPlugin` becomes `code-shiki`.

```ts
import { CodeShikiPlugin } from '@fluxdown/svelte-plugins/plugins/code-shiki';
import { HeadingPlugin } from '@fluxdown/svelte-plugins/plugins/heading';
```

> Import `PRESET_FULL_PLUGINS` and `PRESET_LITE_PLUGINS` from `@fluxdown/svelte-plugins/full` and `@fluxdown/svelte-plugins/lite` respectively. Both can be passed directly to `FluxdownRaw`.

The component's `plugins` prop can extend either preset. See [plugin packs](./aggregate.md) for configuration and composition.
