# Plugin matrix

## Component variants

All three entries share the same component API. Choose the default capabilities you need:

| Component      | Entry                                     | Purpose                                                         |
| -------------- | ----------------------------------------- | --------------------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/taro` or `@fluxdown/taro/full` | Full preset with highlighting, math, CJK and emoji.             |
| `FluxdownLite` | `@fluxdown/taro/lite`                     | Basic Markdown presentation, ready to extend.                   |
| `FluxdownRaw`  | `@fluxdown/taro/raw`                      | Supply the complete `plugins` list and choose every capability. |

### Package

<PluginTag type="taro-plugins" /> refers to `@fluxdown/taro-plugins`, which
provides Taro slots on top of the shared render plugins.

<PluginTag type="react-base-plugins" /> refers to
`@fluxdown/react-base-plugins`, which provides shared rendering and syntax
plugins.

### Import rules

> Import from `<package>/plugins/<plugin-directory>`. Remove the `Plugin` suffix and convert the name to lowercase kebab case: `CodePrismPlugin` becomes `code-prism`, and `TexMathjaxKatexPlugin` becomes `tex-mathjax-katex`. Use the package shown in the table.

```ts
import { CjkPlugin } from '@fluxdown/react-base-plugins/plugins/cjk';
import { CodePrismPlugin } from '@fluxdown/taro-plugins/plugins/code-prism';
import { TexMathjaxKatexPlugin } from '@fluxdown/taro-plugins/plugins/tex-mathjax-katex';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/taro-plugins/full` and `PRESET_LITE_PLUGINS` from `@fluxdown/taro-plugins/lite`.

Pass plugins through the component's `plugins` prop. See [aggregate plugins](./aggregate.md) for declaration, composition and configuration.
