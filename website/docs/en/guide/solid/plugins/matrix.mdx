# Plugin matrix

## Component variants

All three entries share the same component API. Choose the default capabilities you need:

| Component      | Entry                                       | Purpose                                           |
| -------------- | ------------------------------------------- | ------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/solid` or `@fluxdown/solid/full` | Full preset with highlighting, math and diagrams. |
| `FluxdownLite` | `@fluxdown/solid/lite`                      | Basic Markdown presentation, ready to extend.     |
| `FluxdownRaw`  | `@fluxdown/solid/raw`                       | Choose render and slot plugins explicitly.        |

### Package

> <PluginTag type="solid-plugins" /> refers to `@fluxdown/solid-plugins`, which
> provides aggregate plugins, renderers and slots for Solid.

### Import rules

> Import from `@fluxdown/solid-plugins/plugins/<plugin-directory>`. Remove the `Plugin` suffix and convert the name to lowercase kebab case: `CodeShikiPlugin` becomes `code-shiki`, and `TexMathjaxKatexPlugin` becomes `tex-mathjax-katex`.

```ts
import { CodeShikiPlugin } from '@fluxdown/solid-plugins/plugins/code-shiki';
import { TexMathjaxKatexPlugin } from '@fluxdown/solid-plugins/plugins/tex-mathjax-katex';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/solid-plugins/full` and `PRESET_LITE_PLUGINS` from `@fluxdown/solid-plugins/lite`.

Pass plugins through the component's `plugins` prop. See [aggregate plugins](./aggregate.md) for declaration, composition and configuration.
