# Plugin matrix

## Component variants

| Component      | Entry                                                 | Included features                                     |
| -------------- | ----------------------------------------------------- | ----------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/react-lynx` or `@fluxdown/react-lynx/full` | Shiki highlighting, SVG math, CJK and Emoji.          |
| `FluxdownLite` | `@fluxdown/react-lynx/lite`                           | Basic Markdown, tables, images and streaming effects. |
| `FluxdownRaw`  | `@fluxdown/react-lynx/raw`                            | Requires your complete `plugins` list.                |

Full highlights Bash, CSS, HTML, JavaScript, JSON, Python and TypeScript. Unrecognized languages remain plain text. Lite displays code as source text.

`build.tex` defaults to `false`. When enabled, Full typesets math with MathJax SVG and requires SVG XElement in the host. Lite displays formula source; add `TexMathJaxPlugin` for typesetting.

## Code highlighting {#code-highlighting}

Full uses Shiki highlighting and displays source text while initializing or after an error. Android requires Lynx 3.8 or later with [background-thread WebAssembly support](https://lynxjs.org/4.1/guide/scripting-runtime/webassembly.html). Use `CodePrismPlugin` for highlighting without WebAssembly.

## Package and imports

<PluginTag type="react-lynx-plugins" /> is `@fluxdown/react-lynx-plugins`, which
provides React Lynx composite plugins, render plugins and slots.

> Import from `@fluxdown/react-lynx-plugins/plugins/<plugin-directory>`. Remove the `Plugin` suffix from the export name and convert it to lowercase hyphenated words: `CodeShikiPlugin` becomes `code-shiki`.

```tsx
import { CodeShikiPlugin } from '@fluxdown/react-lynx-plugins/plugins/code-shiki';
import { HeadingPlugin } from '@fluxdown/react-lynx-plugins/plugins/heading';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/react-lynx-plugins/full`, or `PRESET_LITE_PLUGINS` from `@fluxdown/react-lynx-plugins/lite`, to pass a preset directly to `FluxdownRaw`.

The component's `plugins` prop can extend any preset. See [composite plugins](./aggregate.md) for configuration and composition.
