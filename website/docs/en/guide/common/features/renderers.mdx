# Side-by-side demo

Watch the same Markdown and text chunks unfold together in React, Vue, Svelte, Angular, React Native, Lynx, Solid, Taro, and uni-app. Switch between static and streaming content, then explore all four effects. On smaller screens, scroll horizontally to see every renderer.

React, Vue, and Svelte are selected by default. Use the selection buttons to choose any number of renderers, keeping at least one selected. Your choices are saved and restored on your next visit. Scroll horizontally to see more columns.

<RendererDemo />

Each column smoothly follows new content to the bottom. Scroll up to read at your own pace, then return to the bottom to follow again. Pause and replay control every renderer together.

React, Vue, Svelte, Angular, and Solid render browser DOM, React Native uses React Native Web, Lynx runs through Lynx Web, Taro uses its H5 components, and uni-app uses the official uni-app x H5 build. They share Markdown and streaming settings; fonts, line wrapping, and animation details can differ between rendering environments.

Bring your own content to the [Playground](/playground) and switch between all nine renderers.
