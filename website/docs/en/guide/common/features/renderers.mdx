# Side-by-side demo

Watch the same Markdown and text chunks unfold together in React, Vue, Svelte, React Native, Lynx, Solid, and Taro. Switch between static and streaming content, then explore all four effects. On smaller screens, scroll horizontally to see every renderer.

All renderers are selected initially. Use the selection buttons to choose which columns to compare, and scroll horizontally to see more.

<RendererDemo />

Each column smoothly follows new content to the bottom. Scroll up to read at your own pace, then return to the bottom to follow again. Pause and replay control every renderer together.

React, Vue, Svelte, and Solid render browser DOM, React Native uses React Native Web, Lynx runs through Lynx Web, and Taro uses its H5 components. They share Markdown and streaming settings; fonts, line wrapping, and animation details can differ between rendering environments.

Bring your own content to the [Playground](/playground) and switch between all seven renderers.
