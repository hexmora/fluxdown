# Side-by-side demo

Watch the same Markdown and text chunks unfold together in React, Vue, React Native, and Lynx. Switch between static and streaming content, then explore all four effects. On smaller screens, scroll horizontally to see every renderer.

<RendererDemo />

Each column smoothly follows new content to the bottom. Scroll up to read at your own pace, then return to the bottom to follow again. Pause and replay control every renderer together.

React and Vue render browser DOM, React Native uses React Native Web, and Lynx runs through Lynx Web. They share Markdown and streaming settings; fonts, line wrapping, and animation details can differ between rendering environments.

Bring your own content to the [Playground](/playground) and switch between all four renderers.
