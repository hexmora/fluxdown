# Smoothing

Streaming text usually arrives in bursts: a few characters in one update, a whole paragraph in the next. Smoothing separates receiving content from displaying it, so those updates appear at a steadier pace.

## See the buffer

This demo receives text in chunks of different sizes. The normal text color marks content already displayed; the other color marks received content still waiting in the buffer. In an application, the buffered text is not visible yet.

<SpringDemo />

When a chunk arrives, the buffer grows first and the visible boundary follows. Pause to inspect their positions, or replay to watch how each incoming chunk changes the pace.

## How the spring sets the pace

The built-in `spring` interpolation moves the visible position like a damped spring pulled toward the end of the received content. A larger backlog pulls harder, so output speeds up; as the visible position approaches the end, it slows down and settles without passing the end. When new content arrives, the spring keeps its current position and velocity and starts pulling toward the new end, so updates flow into one another.

The interpolator computes the position from elapsed time with the spring's exact solution, not by stepping frame by frame. The result does not depend on the frame rate, and no error builds up over a long response. Text can advance between network updates, without a fixed delay for every character. The demo uses the same `SpringSmoothInterpolator` as the `Smooth` mapper.

## Use it in your application

Choose your framework above each example. Pass the Core example’s `mappers` to the [Core inputs](../../core/quick-start.md); Core produces content and effect markers, while your renderer supplies their appearance. The components include those renderers.

Enabling `streaming` uses spring smoothing by default:

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'React Native', 'Lynx']}>

```ts
import type { MapperPluggable } from '@fluxdown/core';
import { Smooth } from '@fluxdown/core-plugins/plugins/mapper/smooth';
import { Scale } from '@fluxdown/core-plugins/plugins/mapper/scale';
import { MutableState, toClosure } from 'stative';

const isStreaming = MutableState.of(true);
const active = toClosure(isStreaming);

const mappers: MapperPluggable[] = [
  [Smooth, { enabled: active }],
  [Scale, { enabled: active }],
];
```

```tsx
import { Fluxdown } from 'fluxdown';

export function Message({
  text,
  isStreaming,
}: {
  text: string;
  isStreaming: boolean;
}) {
  return <Fluxdown streaming={isStreaming} text={text} />;
}
```

```vue
<script setup lang="ts">
import { Fluxdown } from '@fluxdown/vue';

defineProps<{ text: string; isStreaming: boolean }>();
</script>

<template>
  <Fluxdown :streaming="isStreaming" :text="text" />
</template>
```


You can also select the interpolation explicitly and add an [animation effect](./animation/index.mdx):

<FrameworkCodeTabs frameworks={['Core', 'React', 'Vue', 'React Native', 'Lynx']}>

```ts
import type { MapperPluggable } from '@fluxdown/core';
import {
  RafSmoothDriver,
  Smooth,
  SpringSmoothInterpolator,
} from '@fluxdown/core-plugins/plugins/mapper/smooth';
import { Shad } from '@fluxdown/core-plugins/plugins/mapper/shad';

const mappers: MapperPluggable[] = [
  [
    Smooth,
    {
      enabled: true,
      driver: RafSmoothDriver,
      interpolation: SpringSmoothInterpolator,
    },
  ],
  [Shad, { enabled: true }],
];
```

```tsx
import { Fluxdown } from 'fluxdown';

export function Message({ text }: { text: string }) {
  return (
    <Fluxdown
      streaming={{
        smooth: { enabled: true, driver: 'raf', interpolation: 'spring' },
        effect: 'shad',
      }}
      text={text}
    />
  );
}
```

```vue
<script setup lang="ts">
import { Fluxdown } from '@fluxdown/vue';

defineProps<{ text: string }>();
</script>

<template>
  <Fluxdown
    :streaming="{
      smooth: { enabled: true, driver: 'raf', interpolation: 'spring' },
      effect: 'shad',
    }"
    :text="text"
  />
</template>
```

```tsx
import { Fluxdown } from '@fluxdown/react-native';

export function Message({ text }: { text: string }) {
  return (
    <Fluxdown
      streaming={{
        smooth: { enabled: true, driver: 'raf', interpolation: 'spring' },
        effect: 'shad',

      text={text}
    />
  );
}
```

```tsx
import { Fluxdown } from '@fluxdown/lynx';

export function Message({ text }: { text: string }) {

    <Fluxdown
      streaming={{

}
```

Always pass the complete text received so far to `text`. Setting `streaming` to `false` reveals the remaining buffer immediately. Keep smoothing enabled if you want the remaining content to finish appearing gradually.

Core uses the same `Smooth` mapper to produce trimmed content blocks, so the renderer does not need to schedule character updates. See [Core state and updates](../../core/streaming.md#enable-smooth-output) for integration and your framework’s configuration for all options: [React](../../react/configuration.md#streamingsmooth), [Vue](../../vue/configuration.md#streamingsmooth), [React Native](../../react-native/configuration.md), or [Lynx](../../lynx/configuration.md).

The reactive Core example owns its `MutableState`: call `isStreaming.next(false)` when receiving finishes, then dispose `active` and `isStreaming` with `.destroy()` after destroying Core.
