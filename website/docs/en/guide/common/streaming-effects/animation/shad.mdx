# Trailing fade

`shad` fades each newly revealed character from transparent to opaque. Every character plays its own fade from the moment it appears, so the fade keeps going after the stream pauses instead of following the reveal position. Content already displayed stays unchanged.

<AnimationDemo effect="shad" />

## Usage

The following examples use the React component:

```tsx
<Fluxdown streaming={{ effect: 'shad' }} text={text} />
```

Smoothing is enabled by default. The following React component example keeps a shorter tail and allows longer fades:

```tsx
<Fluxdown
  streaming={{ effect: ['shad', { length: 6, duration: 600 }] }}
  text={text}
/>
```

## How the fade adapts

When characters arrive faster, more of them are fading at once. To keep the tail about `length` characters long, each new batch gets a shorter fade while more than `length` characters are in flight: its duration is `duration × length ÷ characters fading`. While fewer characters are fading, every batch uses the full `duration`. A burst that arrives all at once therefore settles quickly, and a slow stream fades in gently.

## Configuration

These fields belong to the `shad` configuration object in `['shad', config]`.

### enabled <span className="field-tag">Optional</span> {#enabled}

**Type:** `boolean`

**Default:** `true`

Enable the trailing fade.

### length <span className="field-tag">Optional</span> {#length}

**Type:** `number`

**Default:** `10`

Number of characters the fade aims to keep in flight at once. Fractions round down; `0` disables the fade, negative values become `0`, and non-finite values use the default.

### duration <span className="field-tag">Optional</span> {#duration}

**Type:** `number`

**Default:** `400`

Longest fade for one character, in milliseconds, used while at most `length` characters are fading. Negative values become `0`, and non-finite values use the default.

> Earlier versions shaded a fixed-width tail with a gradient mask. The `maskWidth` and `hideDelay` options were removed with that mask.
