# Animation

[Smoothing](./smoothing.mdx) controls when content appears. Animation controls how new content enters. You can use them together or enable each separately.

## Trailing fade

`shad` gradually reveals the trailing text while leaving existing content unchanged. It adds a subtle transition at the end of the stream without drawing attention away from reading.

<AnimationDemo effect="shad" />

```tsx
<Fluxdown streaming={{ effect: 'shad' }} text={text} />
```

To match your typography, adjust the number of trailing characters and the mask width:

```tsx
<Fluxdown
  streaming={{ effect: ['shad', { length: 3, maskWidth: 18 }] }}
  text={text}
/>
```

`length` controls the trailing character count, and `maskWidth` is measured in pixels. Their defaults are `10` and `15`.

## Character entrance

`scale` grows new characters from a smaller size while fading them in and clearing their blur. Characters keep their layout space, so existing text stays in place.

<AnimationDemo effect="scale" />

```tsx
<Fluxdown streaming={{ effect: 'scale' }} text={text} />
```

The default entrance lasts `200` milliseconds, starts at scale `0`, and uses a blur radius of `0.08em`. Reduce the amount of change for a gentler effect:

```tsx
<Fluxdown
  streaming={{ effect: ['scale', { duration: 250, from: 0.5, blur: 0.04 }] }}
  text={text}
/>
```

Only newly visible text is animated. Code, formulas, and replacement content keep their existing rendering. `scale` respects the system's reduced-motion preference.

## Combine with streaming

The demos also enable smoothing. Set `smooth: false` to see the animation as each text chunk arrives, or set `effect: false` to keep smooth output without a visual effect.

React includes the mappers and renderers for both effects. In Core, `Shad` and `Scale` create markers that your renderer needs to support. See [React configuration](../../react/configuration.md#streamingeffect) for the options and [Mapper plugins](../../core/plugins/mapper.md) to add your own effect.
