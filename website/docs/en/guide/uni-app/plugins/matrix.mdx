# Plugin matrix

## Component variants

All three entry points share their props. Choose the preset you need:

| Component      | Import                                          | Purpose                                                                           |
| -------------- | ----------------------------------------------- | --------------------------------------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/uni-app` or `@fluxdown/uni-app/full` | Full preset with Prism highlighting, MathJax formulas, CJK, and emoji shortcodes. |
| `FluxdownLite` | `@fluxdown/uni-app/lite`                        | Basic Markdown and streaming effects; add other capabilities as needed.           |
| `FluxdownRaw`  | `@fluxdown/uni-app/raw`                         | Requires explicit `plugins` to assemble your own capabilities.                    |

### Package

<PluginTag type="uni-app-plugins" /> means `@fluxdown/uni-app-plugins`, which
provides uni-app composite plugins, render plugins, and slots.

### Import paths

> Import from `@fluxdown/uni-app-plugins/plugins/<directory>`. Remove the `Plugin` suffix and convert the remaining name to lowercase with hyphens: `CodePrismPlugin` becomes `code-prism`.

```ts
import { CodePrismPlugin } from '@fluxdown/uni-app-plugins/plugins/code-prism';
import { TexMathjaxPlugin } from '@fluxdown/uni-app-plugins/plugins/tex-mathjax';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/uni-app-plugins/full` and `PRESET_LITE_PLUGINS` from `@fluxdown/uni-app-plugins/lite`.

Add capabilities through `plugins`; see [Composite plugins](./aggregate.md) for declaration and composition.
