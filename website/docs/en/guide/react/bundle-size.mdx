# Bundle size

Fluxdown provides Lite and Full entry points. They share Markdown styling, code copying, and streaming features. Their main difference is the dependencies used for code highlighting and formula typesetting. Choose Lite for basic presentation, or the default Full entry for highlighting and complete formula support.

## Lite: basic presentation

Import `FluxdownLite` from `fluxdown/lite`. Code uses a monospace font and formulas display their LaTeX source. This entry does not import Prism, Shiki, KaTeX, or MathJax.

```tsx
import { FluxdownLite } from 'fluxdown/lite';

export function Message({ text }: { text: string }) {
  return <FluxdownLite build={{ tex: true }} text={text} />;
}
```

This demo keeps the code language and copy button, shows code without syntax colors, and displays the formula source. Both versions require `build={{ tex: true }}` to enable formula syntax.

## Full: highlighting and typesetting

Import `Fluxdown` from `fluxdown`, or explicitly from `fluxdown/full`. Full uses Shiki for code highlighting. Formula renderers load on demand, trying KaTeX first and falling back to MathJax when needed. Formula source remains visible while they load.

```tsx
import { Fluxdown } from 'fluxdown';

export function Message({ text }: { text: string }) {
  return <Fluxdown build={{ tex: true }} text={text} />;
}
```

## More plugin options

Neither preset includes the two alternatives below. Install the extension package with `pnpm add @fluxdown/react-presets`, then combine the plugins you need.

| Plugin pack       | Import path                                  | Use case                                                                              |
| ----------------- | -------------------------------------------- | ------------------------------------------------------------------------------------- |
| `CodePrismPlugin` | `@fluxdown/react-presets/plugins/code-prism` | Use Prism for syntax highlighting.                                                    |
| `TexKatexPlugin`  | `@fluxdown/react-presets/plugins/tex-katex`  | Load only KaTeX on demand, without MathJax; show LaTeX source when typesetting fails. |

Add these plugins to Lite to choose your highlighting and formula dependencies:

```tsx
import { CodePrismPlugin } from '@fluxdown/react-presets/plugins/code-prism';
import { TexKatexPlugin } from '@fluxdown/react-presets/plugins/tex-katex';
import { FluxdownLite } from 'fluxdown/lite';

const plugins = [CodePrismPlugin, TexKatexPlugin];

export function Message({ text }: { text: string }) {
  return <FluxdownLite build={{ tex: true }} plugins={plugins} text={text} />;
}
```

Both Lite and Full make `plugins` optional, with supplied plugins taking precedence over their presets. To reduce dependencies, start with Lite and add the capabilities you need. Overriding Full plugins does not remove the Shiki or MathJax dependencies already imported by Full.

For complete control over presets, import `FluxdownRaw` from `fluxdown/raw` and supply its required `plugins` prop. For example, `plugins={PRESET_LIGHT_PLUGINS}` selects all lightweight plugins, or you can list only the plugin packs you need.
