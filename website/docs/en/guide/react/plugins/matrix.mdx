# Plugin matrix

## Component variants

React Lite and React Full share the same component API. Choose the defaults that suit your app:

| Component      | Import path                   | Purpose                                                                                     |
| -------------- | ----------------------------- | ------------------------------------------------------------------------------------------- |
| `FluxdownLite` | `fluxdown/lite`               | Keeps the bundle small with basic Markdown rendering, ready for features you add as needed. |
| `Fluxdown`     | `fluxdown` or `fluxdown/full` | Provides more complete Markdown functionality and richer presentation out of the box.       |

For full control over plugin selection, use `FluxdownRaw` from `fluxdown/raw` and supply `plugins`.
