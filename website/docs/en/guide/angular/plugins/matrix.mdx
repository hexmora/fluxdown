# Plugin matrix

## Component variants

All three entries share the same component API. Choose the default capabilities you need:

| Component      | Entry                    | Purpose                                                         |
| -------------- | ------------------------ | --------------------------------------------------------------- |
| `Fluxdown`     | `@fluxdown/angular`      | Full preset with highlighting, math and diagrams.               |
| `FluxdownLite` | `@fluxdown/angular/lite` | Basic Markdown presentation, ready to extend.                   |
| `FluxdownRaw`  | `@fluxdown/angular/raw`  | Supply the complete `plugins` list and choose every capability. |

### Package

<PluginTag type="angular-plugins" /> refers to `@fluxdown/angular-plugins`,
which provides aggregate plugins, renderers and slots for Angular.

### Import rules

> Import from `@fluxdown/angular-plugins/plugins/<plugin-directory>`. Remove the `Plugin` suffix and convert the name to lowercase kebab case: `CodeShikiPlugin` becomes `code-shiki`, and `TexMathjaxKatexPlugin` becomes `tex-mathjax-katex`.

```ts
import { CodeShikiPlugin } from '@fluxdown/angular-plugins/plugins/code-shiki';
import { TexMathjaxKatexPlugin } from '@fluxdown/angular-plugins/plugins/tex-mathjax-katex';
```

> Import `PRESET_FULL_PLUGINS` from `@fluxdown/angular-plugins/full` and `PRESET_LITE_PLUGINS` from `@fluxdown/angular-plugins/lite`.

Pass plugins through the component's `plugins` input. See [aggregate plugins](./aggregate.md) for declaration, composition and configuration.
